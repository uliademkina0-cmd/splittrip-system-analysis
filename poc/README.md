# Proof of Concept (PoC): Расчетное ядро SplitTrip

Скрипт `currency_split_poc.py` предназначен для проверки ключевых технических гипотез из спецификации требований (`docs/01_SRS.md`):

1. **Интеграция с API ЦБ РФ (`FR-4.2`, `FR-4.3`):** получение исторического курса валют с автоматическим откатом на предыдущий рабочий день, если дата чека приходится на выходной или праздник.
2. **Точное округление долей (`FR-3.3`):** распределение неделимых копеек без использования типов с плавающей точкой (`float`) и с соблюдением правила приоритета (плательщик получает лишнюю копейку в последнюю очередь).
3. **Оптимизация графа долгов (`FR-5.3`):** сведение чистых балансов участников к минимальному количеству банковских переводов.

## Требования и запуск

Скрипт написан на стандартной библиотеке Python 3.10+ и не требует установки внешних пакетов.

```bash
python currency_split_poc.py
```
